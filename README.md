# FindOldStreet

The application is in [site/](site/README.md). The [coverage report](site/COVERAGE.md) records actual city/locality coverage, source evidence and known gaps.

Run `cd site`, then follow the setup and preview instructions in the application README.
This project uses one Git repository at the project root. `site/` is a regular tracked directory, not a separate repository or submodule. Run Git commands from either directory; both use the same history and branch. The root `vercel.json` builds the application into `site/dist`.
